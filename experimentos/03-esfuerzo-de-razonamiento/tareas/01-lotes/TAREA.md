# Lotes de un iterable
Implementá `lotes(elementos, tamano)`: devolvé una lista de listas, en orden, de hasta `tamano` elementos. Conservá el último lote incompleto y aceptá iterables de una sola pasada. No alteres la entrada. Para un iterable vacío devolvé `[]`. Rechazá con `ValueError` un tamaño que no sea un `int` positivo; los booleanos tampoco valen.

Editá únicamente `lotes.py`. Usá sólo la biblioteca estándar de Python. No modifiques este enunciado ni agregues otros archivos. No accedas a Internet ni delegues.
