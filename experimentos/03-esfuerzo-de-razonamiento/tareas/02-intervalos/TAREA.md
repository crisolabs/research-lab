# Unión de intervalos
Corregí `unir(intervalos)`. Cada intervalo contiene exactamente dos números enteros o flotantes finitos, con inicio menor o igual al fin. Ante intervalos mal formados o extremos inválidos (incluidos booleanos) lanzá `ValueError`. Devolvé listas `[inicio, fin]`, ordenadas, uniendo intervalos cerrados superpuestos o que se tocan. La entrada puede ser un iterable; no la modifiques. Entrada vacía: `[]`.

Editá únicamente `intervalos.py`. Usá sólo la biblioteca estándar de Python. No modifiques este enunciado ni agregues otros archivos. No accedas a Internet ni delegues.
